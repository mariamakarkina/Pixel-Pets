# PIXEL PETS — Telegram Tamagotchi

MVP Telegram-бота на Python + aiogram 3 + SQLite.

## Возможности
- случайное вылупление питомца с шансами редкости 50/25/15/8/2%;
- коллекция питомцев и один активный питомец;
- показатели голода, настроения, энергии и здоровья;
- ленивое обновление показателей при взаимодействии;
- кормление яблоком, игра, сон, лечение;
- магазин и инвентарь;
- ежедневные монеты и серия входов;
- переименование питомца через `/rename Новое имя`.

## Запуск на Windows
1. Установи Python 3.11 или новее.
2. Распакуй архив.
3. Открой терминал в папке проекта.
4. Выполни:
   ```powershell
   py -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
5. Скопируй `.env.example` в `.env`.
6. Вставь токен, полученный у `@BotFather`, в `BOT_TOKEN`.
7. Запусти:
   ```powershell
   python bot.py
   ```

## Создание бота в Telegram
1. Открой `@BotFather`.
2. Отправь `/newbot`.
3. Укажи отображаемое имя и username, который заканчивается на `bot`.
4. Скопируй токен в `.env`.

**Не отправляй токен в публичные чаты и не загружай `.env` на GitHub.**

## Важно
Это первая MVP-версия. Для публичного запуска стоит добавить:
- защиту от повторных нажатий и более подробную обработку ошибок;
- выбор питомца из коллекции и переименование через диалог;
- эволюцию, достижения, рейтинги и мини-игры;
- часовые пояса и отдельный сервис уведомлений;
- PostgreSQL и резервное копирование для большого числа игроков.

Состояния питомцев рассчитываются по времени при открытии/действии, без постоянных фоновых таймеров.
